## Создание пользователя
Для создания нового пользователя, задания ему пароля и добавления в группу admin были последовательно выполнены следующие команды (выполняются с правами суперпользователя через sudo):
1.    Создание нового пользователя:
	Команда: 
```bash
sudo adduser student
```
	Пояснение: Утилита интерактивно запрашивает ввод пароля для нового пользователя (пароль не отображается при вводе в целях безопасности), а также предлагает ввести дополнительные данные (Полное имя, номер комнаты и т.д. – их можно пропустить клавишей Enter)

2.    Добавление нового пользователя в группу admin:
	Команда: 
```bash
sudo usermod -aG admin student
```
	Пояснение: В новых версиях Ubuntu группа администраторов называется sudo, в таком случае команда выглядит как sudo usermod -aG admin student

3.    Вход в систему под новым пользователем:
	Команда:
```bash
su - student
```
	Пояснение: Команда su (substitute user) позволяет переключиться на созданного пользователя прямо в текущем терминале. Система запросит пароль пользователя student.

```bash
sudo adduser student
sudo usermod -aG admin student
su - student
```

## Ответы на вопросы

### 1. Что такое терминал?
Терминал (или эмулятор терминала/консоли) – это программа, обеспечивающая текстовый интерфейс взаимодействия пользователя с командной оболочкой (шеллом) операционной системы. Терминал принимает текстовые команды (CLI – интерфейс командой строки), передает их оболочке на исполнение и выводит результат работы программ в виде текста на экран.

### 2. Основные каталоги Linux
В Linux используется единое дерево каталогов. Основными стандартными системными каталогами являются:
·      /bin и /sbin – основные системные программы и утилиты администратора.
·      /boot – файлы для загрузки ОС (ядро, загрузчик).
·      /etc – глобальные конфигурационные файлы программ и системы.
·      /home и /root – домашние каталоги обычных пользователей и суперпользователя соответственно.
·      /dev – файлы подключенных физических и виртуальных устройств.
·      /lib – системные библиотеки.
·      /media и /mnt – точки монтирования съёмных носителей и дисков.
·      /var – часто изменяющиеся файлы (логи, кеши, базы данных).
·      /usr – установленные программы пользователя, документация, исходные коды.
·      /tmp – временные файлы.
·      /proc – виртуальная файловая система с информацией о ядре и процессах.

### 3. Типы файлов
В Linux применяется принцип «все есть файл». Выделяются следующие типы:
·      Обычные файлы (regular files): текстовые документы, картинки, исполняемые бинарные программы.
·      Каталоги (directories): специальные файлы, содержащие списки ссылок на другие файлы.
·      Файлы устройств: интерфейсы для работы с драйверами аппаратуры. Делятся на блочные (жесткие диски, флешки) и символичные/байт-ориентированные (клавиатуры, мыши).
·      Символические ссылки (symlinks): файлы, хранящие путь-указатель на другой файл или каталог (анализ ярлыков).
·      Именованные каналы (named pipes) и сокеты (sockets): специальные файлы, используемые для обмена данными между работающими процессами.
