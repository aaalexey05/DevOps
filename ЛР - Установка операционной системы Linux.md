# Лабораторная работа  
## Установка операционной системы Linux  

## Цель работы

Изучить процесс установки операционной системы Linux (Ubuntu) на виртуальную машину, освоить базовые навыки настройки системы, работы с терминалом и управления правами доступа пользователя, а также выполнить первоначальную настройку сети в среде виртуализации.

---

## Ход работы

1. Установили виртуальную машину с использованием программного обеспечения Oracle VirtualBox. В качестве операционной системы выбрали Linux Ubuntu.  
![[Pasted image 20260319234815.png]]
2. Выполнили установку операционной системы Ubuntu на виртуальную машину, следуя стандартному мастеру установки.  
3. После завершения установки запустили систему и открыли терминал.  
4. Выполнили обновление пакетов с помощью команды:
   sudo apt update
   (вводим пароль пользователя)
5. При возникновении ошибки:
   user_name is not in sudoers file. This incident will be reported.
![[Pasted image 20260319234857.png]]
   Выполнили вход под пользователем root:
   su root
![[Pasted image 20260319234906.png]]
6. Отредактировали файл:
   /etc/sudoers
![[Pasted image 20260319234920.png]]
   Добавили пользователя в список sudoers для предоставления прав администратора.  
   Сохранили изменения:
   CTRL + O → Enter  
   CTRL + X  
7. Повторно выполнили команду:
   sudo apt update
   Убедились в корректной работе.
8. Настроили сетевое подключение в Oracle VirtualBox, выбрав тип подключения «Сетевой мост» для обеспечения доступа к сети.
![[Pasted image 20260319234935.png]]
9. Проверили работоспособность сети и корректность выполнения всех настроек.
