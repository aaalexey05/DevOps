## Ход работы
---
### 1. Определение текущего каталога
```bash
pwd
```
Текущий путь: `/home/user`

---
### 2. Переход в корневой каталог
```bash
cd /
```
Текущий путь: `/home/user`

---
### 3. Просмотр содержимого каталога
```bash
ls
```
Файлы: `documents`, `examples`

---
### 4. Возврат в домашний каталог
```bash
cd
```
Команда без параметров возвращает в домашний каталог.

---
### 5. Создание каталога `test`
```bash
mkdir test
```
Создает новую папку.

---
### 6. Переход в каталог `test`
```bash
cd test
```
Переход внутрь папки.
![[Pasted image 20260320000235.png]]

---
### 7. Просмотр содержимого каталога
```bash
ls
```
Каталог пуст.

---
### 8. Создание каталога `test2`
```bash
mkdir test2
```

---
### 9. Создание файла `text`
```bash
touch test2/text
```

---
### 10. Переименование файла
```bash
mv test2/text test2/textSIT
```
![[Pasted image 20260320000248.png]]

---
### 11. Копирование файла
```bash
cp test2/textSIT test2/copy.txt
```

---
### 12. Создание жесткой ссылки
```bash
ln test2/copy.txt test2/link
```

---
### 13. Создание символической ссылки
```bash
ln -s copy.txt test2/simlink
```

---
### 14. Просмотр содержимого каталога
```bash
ls -la test2
```
![[Pasted image 20260320000257.png]]

---
### 15. Удаление файлов
```bash
rm test2/textSIT test2/copy.txt test2/link test2/simlink
```
Удаляет все созданные файлы и ссылки.

---

## Вывод

В ходе работы были изучены базовые команды Linux: навигация по файловой системе, создание файлов и каталогов, работа со ссылками и удаление файлов.
